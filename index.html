项目说明
本作品集围绕亚马逊精品运营全链路，呈现选品调研、Listing 与流量诊断、广告投放复盘、库存与 FBA 周转、口碑维护六个分析模块。
数据口径声明：店铺明细为按公开行业基准规律建模的演示数据，用于展示分析框架与指标拆解方法，非任何真实店铺的经营业绩；页面中的行业基准区间引自公开报告，来源见页末。

分析类目

  • Home Improvement / Hand Tools
  • 五金工具套装、家用工具组
  • 美国站，18 个 SKU，12 个月周期

核心方法

  • 竞品与市场容量调研（卖家精灵口径）
  • 漏斗诊断与关键词排名复盘
  • SP/SB/SD 广告结构与 ACoS/TACoS 复盘
  • IPI、WOC 库存周转分层与备货建议

工具与数据

  • Excel / SQL / Python（Pandas）/ Tableau 口径
  • ECharts 可视化，指标可追溯到原始报表
  • 基准对照：类目均值 vs 本店表现

公开基准与口径来源

  • SellerApp《2026 Advertising Benchmark Report》：分品类 ACoS / TACoS / CTR / CVR / CPC / ROAS 区间
  • Triple Whale Amazon Benchmarks 2026：类目 ROAS、AOV、CVR、CTR、CPA 均值对照
  • 亚马逊卖家中心官方帮助：IPI 库存绩效阈值（>450 良好 / >550 优秀 / <350 仓储限制）与 FBA 库存周转口径
  • 卖家精灵选品调研指南：市场容量、评论壁垒、价格带与差异化空间的判断方法口径

说明：本店演示数值按上述公开基准的合理区间建模；指标定义（ACoS＝广告花费/广告销售额，TACoS＝广告花费/总销售额，WOC＝现有库存/周均销量）采用行业通用口径。

经营总览
近 30 天核心经营指标，并与 Home & Kitchen 类目公开基准对照。

12 个月 GMV 与广告投入

柱：GMV（千美元）；折线：广告花费（千美元）与 TACoS（%）

本店 vs 类目基准

CVR / CTR / ACoS / 毛利率，基准区间取 Home & Kitchen 公开报告
选品与竞品分析
竞品短名单、竞争象限与选品五维评分；市场容量、垄断度与评论依赖度判断切入缝隙。

竞品短名单（5 个代表 ASIN）

价格、评论数、评分、估算月销、BSR 与毛利估算；成熟爆款 / 新品黑马 / 中游竞品分层对比。

竞争象限：评论壁垒 × 需求规模

横轴：累计评论数（竞争壁垒）；纵轴：估算月销（需求）；气泡大小＝售价

目标新品选品五维评分

市场容量、竞争强度、利润空间、差异化空间、供应链成熟度（满分 100）
Listing 与流量诊断
转化漏斗、关键词排名与 Listing 要素诊断，定位卡在哪一环。

流量转化漏斗（近 30 天）

曝光 → 点击 → 加购 → 下单；CTR＝点击/曝光，点击 CVR＝下单/点击

核心关键词排名

自然搜索排名与主要广告位；排名越靠前数值越小

Listing 要素诊断

标题、五点、主图、A+、后台关键词、价格竞争力分项评分（满分 10）
站内广告复盘
SP / SB / SD 分类型效率，ACoS 与 TACoS 走势，关键词矩阵与否词建议。

分广告类型效率

ACoS 与 ROAS 对照；SP 跑词收单、SB 打品牌词、SD 做再营销与竞品定位

ACoS 与 TACoS 走势

ACoS 下降且 TACoS 同步回落，说明广告在带动自然排名；若 ACoS 平而 TACoS 升，则依赖付费流量

关键词矩阵与处置建议

按曝光、点击、CPC、订单与 ACoS 分层：放量 / 观察 / 优化否词
库存与 FBA 周转
IPI 库存绩效、可维持销售周数（WOC）分层与 SKU 备货建议。

IPI 库存绩效

>450 良好，>550 优秀，<350 面临仓储限制（亚马逊官方口径）

SKU 按 WOC 分桶

健康区间 4–8 周；<4 周缺货风险，>8 周冗余积压

代表 SKU 周转与备货建议

周销、现有库存、在途、WOC 与处置动作

费用结构（占 GMV）

平台佣金约 15%；FBA 配送与头程为主要履约成本；毛利在扣除广告前口径
口碑与复盘改进
星级分布、差评归因、好评标签与退货率趋势，输出闭环改进项。

星级分布

近 90 天 Review 星级占比

差评归因

1–3 星评价问题归类，定位需反哺产品与 Listing 的环节

好评标签

高频正向反馈，可提炼为 Listing 卖点

退货率趋势（近 6 个月）

类目可接受区间一般 <10%
